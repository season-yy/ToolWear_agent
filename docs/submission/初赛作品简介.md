# 初赛作品简介

## 项目名称

刃知：基于 AgentTeams 的刀具磨损监测算法辅助平台

## 500 字以内简介

刃知面向刀具磨损研究中“数据能采、算法难选、实验难复现”的实际问题，把多通道信号建模过程变成可配置、可审批、可追溯的多智能体实验闭环。系统以官方 AgentTeams 为协同底座，由实验主控、数据治理、算法架构、代码训练、评估治理、报告记忆六个 Agent 分工。用户在网页定义数据、标签、滑窗、小样本比例和任务目标；LLM 结合项目背景生成 Registry 兼容候选，经人工确认后，系统执行真实训练与评估，再由专家 Agent 读取指标、混淆矩阵、t-SNE 和历史结果，给出调参、换方案或停止建议。当前已在 PHM2010 C1 上完整跑通：315 个 cut 按来源隔离，训练、验证、测试无泄漏，20% 小样本验证 Macro-F1 达 0.9375；实验最终归档并保存代码快照、日志、Trace 和 28 项证据。平台保留人工审批、最终测试隔离和失败重试边界，后续将扩展 C4/C6 跨刀具迁移、磨损值回归和企业数据接入。
