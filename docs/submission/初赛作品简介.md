# 初赛作品简介

## 项目名称

刃知：基于 AgentTeams 的刀具磨损监测算法辅助平台

## 简介

刀具磨损研究常面临多通道数据处理复杂、算法选型依赖经验、实验难复现等问题。刃知以官方AgentTeams为协同底座，由实验主控、数据治理、算法架构、代码训练、评估治理和报告记忆六个Agent分工，将数据准备、候选生成、真实训练、评估决策和证据归档组成闭环。用户可在网页配置数据、标签、信号通道、滑窗和小样本策略；LLM结合任务目标与硬件条件，从受控Registry生成2至3个候选Pipeline，经人工批准后训练。系统按完整cut切分数据，防止同一CSV窗口跨训练、验证和测试集；小样本仅从训练集分层抽取，最终测试集在方案锁定前隔离。训练后输出Macro-F1、Balanced Accuracy、混淆矩阵和t-SNE，专家Agent给出调参、换方案或停止建议。每个Agent均具有独立身份、输入输出Schema、Skill权限和失败边界，关键状态由SQLite持久化，页面或服务重启后仍可恢复实验。配置、模型、图表和报告通过统一Trace关联，并以哈希校验证据完整性，方便科研人员比较方案，也便于评委或团队成员复验结果。平台具备人工审批、失败重试、Registry白名单和Evidence追踪能力。当前已在PHM2010 C1上跑通315个cut、7通道实验，20%小样本验证Macro-F1达0.9375，并归档代码、模型、日志、Trace和28项证据。模块化数据适配器和Pipeline注册机制可迁移到轴承、齿轮等工业时序诊断场景，后续将扩展C4/C6迁移、VB回归和企业数据接入。
