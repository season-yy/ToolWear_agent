# 初赛作品简介

## 项目名称

刃知：基于 AgentTeams 的刀具磨损监测算法辅助平台

## 简介

刀具磨损研究常面临多通道数据处理复杂、算法选型依赖经验和实验难复现等问题。刃知以官方AgentTeams为协同底座，由实验主控、数据治理、算法架构、代码训练、评估治理和报告记忆六个Agent分工，形成数据准备、候选生成、人工审批、真实训练、评估决策和证据归档闭环。用户可在网页配置数据、标签、通道、滑窗和小样本策略；LLM结合任务目标，从受控Registry生成可执行Pipeline。系统按完整cut切分，小样本仅从训练集分层抽取，最终测试集在方案锁定前隔离。训练后输出Macro-F1、Balanced Accuracy、混淆矩阵和t-SNE，专家Agent给出调参、换方案或停止建议。区别于仅对话的方案，刃知为Agent配置独立身份、Schema、Skill权限和失败边界，以SQLite恢复状态，以Trace和Evidence关联代码、模型、图表、日志和报告。当前已在PHM2010 C1上跑通315个cut、7通道实验，20%小样本验证Macro-F1达0.9375，并归档28项证据。模块化数据适配器、Pipeline Registry和Skill契约可复用于其他工业时序诊断。
